# ⚡ GeodeSync v2.2.0 • Full UI Overhaul & Streamlined Dashboard

GeodeSync v2.2.0 delivers a **complete, ground-up UI overhaul** designed to make the dashboard dramatically cleaner, simpler, and more intuitive while keeping 100% of all companion tools and power features intact.

---

### ✨ What's New in v2.2.0

- 🎯 **Consolidated Hero Dashboard Card:**
  - Merged player profile, live Geometry Dash stats (⭐ Stars, 👿 Demons, 🌙 Moons, 💎 Diamonds, 🪙 Coins, 🔮 Orbs), and real-time game status chips (`GD 2.2081`, `Geode v5.11.2`, `Protected`, `Steam Found`) into a single unified card.
  - Replaced duplicate launch buttons with a single **▶️ Play Geometry Dash (Boosted)** action button that automatically launches with Windows kernel `HIGH_PRIORITY_CLASS` for ultra-low latency gameplay.

- 🧩 **Sleek 4-Column Companion Tools Grid:**
  - All 16 companion tools and mods are organized cleanly into an intuitive 4×4 dashboard:
    - **Mod Manager**, **Backup Saves**, **Save Doctor**, **FPS Unlocker**
    - **NONG Songs**, **Essential Mods**, **Cache Cleaner**, **Crash Doctor**
    - **Game Profiles**, **Auto-Backup**, **Discord RPC**, **GD Sounds**
    - **Run in BG**, **Check Updates**, **Restore Steam GD**, **Desktop Shortcut**

- 📋 **Clean 1-Line Status Ticker & Activity Log Viewer:**
  - Removed the massive terminal log box from the main view, freeing up screen real estate and eliminating visual clutter.
  - Added a live 1-line status ticker in the footer with a dedicated modal popup (`📋 Activity Log`) for power users to inspect and export logs.

- ⚡ **Auto-Boosted Gameplay:**
  - High CPU Priority (`HIGH_PRIORITY_CLASS`) is now built into the main play button on Windows with seamless fallback to Steam.
