# GeodeSync v2.0.2 • Verified Discord Rich Presence & In-App Sharing

This update rolls out full **Discord Rich Presence** integration with verified Geometry Dash status, live viral profile buttons, automatic background reconnects, and in-app sharing tools for the GD community.

---

### 🚀 What's New in v2.0.2:

* 🎮 **Discord Rich Presence Live:**
  * Verified Geometry Dash application status (`Playing Geometry Dash` / `Geode Mods Protected 🛡️`).
  * Live elapsed activity timer and active GD version display.
  * Clickable **`[ Get GeodeSync ]`** profile button so your Discord friends can download GeodeSync in 1 click!
  * Background daemon reconnect loop — launches and reconnects automatically even if Discord is opened after GeodeSync or restarted.
  * In-App toggle button (`🎮 Discord RPC: ON/OFF`) directly in the tools grid.

* 📢 **In-App Viral Share Tool:**
  * Added **"📢 Share GeodeSync"** button with pre-written, 1-click copyable messages for Discord servers, Reddit, and Twitter.
  * Added **"⭐ Star on GitHub"** 1-click button.

* ⚡ **Cross-Platform Auto-Updater:**
  * Seamless 1-click updates across Windows, macOS, and Linux/Steam Deck.
