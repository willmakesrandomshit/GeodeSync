# GeodeSync v2.0.9 • Muted by Default

In response to community feedback, audio/sound effects are now completely muted and turned **OFF by default**.

---

### 🌟 What's Changed in v2.0.9:

* 🔇 **Sounds Disabled by Default:**
  * GeodeSync no longer plays sounds upon completing operations by default.
  * The tool button now defaults to `🔇 GD Sounds: OFF`.
  * Users who wish to enable sound effects can simply toggle the button to `🔊 GD Sounds: ON` in More Tools at any time.
