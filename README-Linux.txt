HOW TO RUN ON LINUX / STEAM DECK:
1. Extract this archive.
2. Open a terminal in this directory.
3. Make the runner executable and run it:
     chmod +x run-geodesync-linux.sh
     ./run-geodesync-linux.sh
   (Or right-click run-geodesync-linux.sh -> Properties -> Allow executing file as program -> Run)

REQUIREMENTS:
- Python 3 with Tkinter (sudo apt install python3 python3-tk on Ubuntu/Debian, or pacman -S python-tk on Arch)
- Geometry Dash on Steam (Proton)
