### 🛠️ What GeodeSync Does

* ⚡ **1-Click Version Switch:** Downloads and installs Geometry Dash 2.2081 safely through Steam so your Geode mods work instantly.
* 🔒 **Steam Update Lock:** Freezes Steam updates so Steam won't overwrite your game when RobTop pushes an update.
* 🛡️ **Auto Save Protection:** Automatically backs up your `.dat` save files before any file changes, plus includes a built-in Save Doctor.
* 📦 **1-Click Essential Mods:** Install Globed, Click Between Frames (CBF), Jukebox, BetterEdit, and Click Sound in one click.
* 🔄 **Built-In Auto-Updater:** Automatically checks for updates and upgrades itself in 1 click.
