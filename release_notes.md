# GeodeSync v1.1.5.4 — clearer dashboard and safer updates

- Refresh the dashboard with a calmer plum, lime, lilac, and warm neutral palette.
- Make the recommended next step the main focus, with shorter labels and clearer setup status.
- Keep optional utilities together in a collapsed **More tools** drawer.
- Select the highest published stable release by numeric version instead of trusting GitHub's latest-release pointer.
- Recheck the selected version before downloading, and never offer an older release as an update.
- Update app and Windows file version metadata to match the release.

This update includes the macOS depot validation and transactional game replacement from v1.1.5.2, plus the simpler dashboard from v1.1.5.3.
