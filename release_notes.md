# GeodeSync v1.1.5.1 — Consolidated hotfix

## macOS downgrade safety

- Reject incomplete cached Geometry Dash app bundles before installing them. A damaged or partial Steam depot is sent through the download path instead of being mistaken for a finished download.
- Treat malformed `Info.plist` XML as an invalid app bundle, with a useful validation error instead of an uncaught parser exception.
- Preserve the installed game app if the downloaded bundle fails validation or the replacement fails.

## Steam recovery and launch

- Prevent repeated clicks from starting overlapping downgrades.
- Stop Restore to Latest GD if Steam's app manifest cannot be safely unlocked.
- Verify macOS manifest lock and unlock operations, rolling back a failed lock attempt.
- Keep the macOS launch monitor waiting for Steam and report whether the game process actually starts.

## Update safety

- Compare numeric release versions and refuse to present or install an older GeodeSync release as an update. This keeps a version label such as `1.1.3.1` from downgrading users already on `1.1.5`.
- Continue verifying Mac update checksums, architecture, and app bundle before replacing GeodeSync.

## Platform builds

- Windows, Apple silicon, and Intel Mac builds are generated by GitHub Actions. Mac builds include Python, Tcl, and Tk; no separate Python install or Terminal launch is required.
- Unsigned community builds may require Control-click → Open once in macOS.
